# 🍽️ Restaurant Table Reservation System (PHP & MySQL)

Aplicación web full-stack desarrollada para la gestión automatizada de reservas en el sector de la restauración, implementando buenas prácticas de seguridad de datos mediante consultas preparadas en PHP (PDO) y un diseño adaptable.

## ✨ Características Principales
* **Formulario de Registro Dinámico:** Captura de datos del cliente (nombre, apellido, edad, contacto, fecha, número de comensales y selección de turno).
* **Gestión de Base de Datos Relacional:** Almacenamiento persistente estructurado en MySQL mediante phpMyAdmin.
* **Seguridad contra Inyecciones SQL:** Uso estricto de sentencias preparadas en PHP (`PDO`).
* **Módulo de Listado y Filtrado en Tiempo Real:** Visualización de registros tabulados con capacidad de filtrado cruzado por turno (*Comida* o *Cena*).
* **Diseño UI/UX Limpio:** Estilos personalizados en CSS orientados a una experiencia de usuario fluida.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Backend:** PHP (Programación Orientada a Objetos / PDO)
* **Base de Datos:** MySQL / phpMyAdmin / Entorno XAMPP
* **Frontend:** HTML5, CSS3
* **Control de Versiones:** Git & GitHub
